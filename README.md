# 마비노기 모바일 거래소 감시

거래소 시세를 보고, 조건이 맞으면 알려주는 개인용 도구.

- **화면**: <https://scarzsearch-cyber.github.io/mobi-market/>
- **서버 감시**: 10분마다 자동 실행 (탭을 닫아도, 컴퓨터를 꺼도 알림이 옴)

---

## 지금 상태

| | 상태 |
|---|---|
| 화면 (시세·차트·신호 점수·제작 계산기) | ✅ 동작 |
| 서버 감시 워크플로 | ✅ 동작 (10분마다) |
| 감시 대상 설정 (`alerts/settings.json`) | ✅ 등재됨 — 파동의 영혼석 |
| **알림 발송** | ⏸ **`MOBI_API_KEY` 등록 대기** |

### 남은 한 가지

저장소 **Settings → Secrets and variables → Actions → New repository secret**

| 이름 | 값 |
|---|---|
| `MOBI_API_KEY` | 모비라이프 API 키. 여러 개면 줄바꿈/쉼표로 전부 넣으면 돌려 쓴다 |

이거 하나 넣으면 감시가 바로 돌기 시작한다. **키를 여러 개 갖고 있다면 화면에서 쓰는
것과 다른 키를 주는 게 좋다** — 같은 키를 둘이 나눠 쓰면 분당 30회 한도를 경쟁해서
화면에서 429 가 뜬다. 알림은 **GitHub 이슈 댓글 → 메일**로 온다
(추가 설정 없음 — `GITHUB_TOKEN` 은 워크플로가 이미 갖고 있다).

카카오톡으로 받고 싶으면 `KAKAO_REST_KEY` · `KAKAO_REFRESH_TOKEN` 을 더 넣으면 그쪽이
우선된다. **필수가 아니다** — 카카오는 앱 등록·로그인이 필요하고 토큰이 두 달마다
만료돼서 사람이 다시 갈아줘야 하므로, 기본 통로로 두지 않았다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전부 (단일 파일, 빌드 없음, 바닐라 JS) |
| `alerts/watch.py` | 서버측 감시·판정·발송 |
| `alerts/settings.json` | 무엇을 어떤 조건으로 감시할지 |
| `alerts/state.json` | 봇이 관리 (main 아님 — `alerts-state` 브랜치) |
| `alerts/test_rules.py` · `test_flow.py` | 판정 규칙·전체 흐름 테스트 (시크릿 없이 실행됨) |
| `.github/workflows/alerts.yml` | 10분마다 실행 |

자세한 내용은 [`alerts/README.md`](alerts/README.md).

### 화면과 서버의 역할 분담

- **서버가 판정하는 것**: 저가하락·저가상승·신규매물·품귀·목표가·트레일링.
  전부 "최신 스냅샷 하나 + 직전 값"만으로 결정되는 것들이라 서버에서 그대로 재현된다.
- **화면만 판정하는 것**: 종합 신호 점수(🟢사기 좋음 / 🔴팔기 좋음)와 TEMA 추세전환.
  시세이력 백분위·이동평균이 필요한데, 그걸 파이썬으로 옮기면 **같은 숫자를 만드는 구현이
  둘**이 된다. 한쪽만 고치면 화면과 알림이 서로 다른 값을 말하게 되므로 화면을 유일한
  출처로 남겼다.

## 신호 점수에 대해 (검증 중)

점수의 주 지표는 "과거 7일 분포에서 지금 가격이 얼마나 극단적인가"이고, **공급이 그 세기를
조절한다** (최대 ±35%, 방향은 바꾸지 않는다):

| 가격 신호 | 공급 | 결과 |
|---|---|---|
| 싸다 | 마름 | 증폭 — 오르기 전에 사둔다 |
| 싸다 | 쏟아짐 | 감쇠 — 더 내린다, 기다려라 |
| 비싸다 | 쏟아짐 | 증폭 — 떨어지기 전에 판다 |
| 비싸다 | 마름 | 감쇠 — 더 오른다, 쥐고 있어라 |

⚠️ **이 가중치는 아직 데이터로 검증된 값이 아니다.** 시장 구조에서 나온 가설이다.
그래서 화면이 (시각·최저가·수량)을 10분에 하나씩 기록해두고, **적중률 탭 → 📉 수량 → 가격
검증**에서 실제로 그런지 직접 세어볼 수 있게 해뒀다. 하루쯤 쌓이면 판정이 나온다.

세기를 바꾸려면 `index.html` 의 `SUPPLY_TILT` 한 곳만 고치면 된다 (`0` 이면 공급을 안 봄).
