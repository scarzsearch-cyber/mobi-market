    💬 카카오톡 (나에게 보내기) 미설정
    Kakao Developers(developers.kakao.com) → 내 애플리케이션 → 앱 키에서 JavaScript 키와 REST API 키를 둘 다 여기에 입력하세요. 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인과 앱 설정 → 카카오 로그인 → Redirect URI 두 곳에 지금 이 페이지 주소()를 정확히 등록해야 로그인이 됩니다. "카카오 로그인 → 동의항목"에서 "카카오톡 메시지 전송"을 사용 설정으로 켜둬야 합니다.
    🌙 조용한 시간대 ~
    이 시간대엔 카카오톡만 억제돼요 (브라우저 알림/소리는 그대로 울립니다).
    ⏳ 동일 아이템 재알림 간격 분
    한 아이템에 카톡이 한 번 가면, 이 시간 동안은 같은 아이템으로 조건이 다시 맞아도 카톡을 또 보내지 않아요 (0으로 두면 매번 전송). 브라우저 알림/소리는 이 설정과 무관하게 항상 울려요.
    🎯 종합 스코어 필터 이상일 때만 카톡
    개별 알림이 울려도 감시목록의 종합 신호 스코어(절대값)가 이 값보다 작으면 카톡은 건너뛰어요 (0=필터 안 함, 전부 전송). 진짜 중요한 신호만 폰으로 받고 싶을 때 올려보세요 — 역시 브라우저 알림/소리는 항상 그대로 울립니다.
    🖥 종합 스코어 필터 이상일 때만 컴퓨터 알림
    개별 알림이 울려도 종합 신호 스코어(절대값)가 이 값보다 작으면 브라우저 알림·소리·탭 깜빡임까지 전부 건너뛰어요 (0=필터 안 함, 전부 표시). 스코어가 낮으면 사도 팔아도 이득이 없는 구간이라, 진짜 신호만 보고 싶을 때 올려보세요. 카카오톡 필터와는 별개 설정이에요.
    ⏱ 자동갱신 주기 감시 목록이 크거나 API 한도가 자주 걸리면 주기를 늘려보세요.
    💾 설정 백업
    감시 목록·알림 설정·조용한 시간대 등을 파일로 저장해뒀다가, 브라우저를 바꾸거나 캐시가 날아갔을 때 불러올 수 있어요. (API 키·카카오 로그인 정보는 보안상 포함되지 않아요 — 새 기기에선 직접 입력해주세요.)
    🤖 서버 감시 동기화 확인 중…
    탭을 닫아도 오는 폰 알림은 저장소의 alerts/settings.json을 보고 돌아요. 이 칸에 토큰을 넣어두면 감시 목록·알림 조건을 바꿀 때마다 화면이 알아서 그 파일을 갱신해서, 손으로 내보내고 올릴 일이 없어집니다.

    토큰은 Fine-grained personal access token으로 만들고 이 저장소 하나만 대상으로, 권한은 Contents: Read and write 하나만 주세요. 그렇게 하면 혹시 새더라도 이 게임 저장소 말고는 아무것도 못 건드립니다(계정 전체 권한이 아니에요). 만료일도 짧게 잡아두시고, 언제든 한 번에 폐기할 수 있어요.
    토큰을 안 넣어도 됩니다 — 그 경우엔 서버 설정이 여기와 달라졌을 때 알려주기만 하고, 반영은 아래 [내보내기]로 받은 파일을 alerts/settings.json으로 올리시면 돼요.
    🎨 이평선 스타일
    HMA 두께 TEMA 두께
    선 명암 (0=투명 ~ 1=불투명, HMA/TEMA 공통)
    HALO 두께 HALO 명암
    HALO는 이평선 뒤에 깔리는 검은 외곽선이에요 (0으로 두면 외곽선 없이 선만 나와요). 값 바꾸면 차트에 바로 반영돼요.

    📉 수량 → 가격 검증
    "수량이 줄면 가격이 오른다"는 이 앱 신호 점수의 핵심 가정이에요. 감시 중인 아이템의 (시각·최저가·수량)을 10분에 하나씩 남겨두고, 그 가정이 실제로 맞는지 직접 세어봅니다. 신호 점수의 공급 가중치는 아직 이 데이터로 검증된 값이 아니라 시장 구조에서 나온 가설이에요.
    [지금 분석]을 누르면 지금까지 쌓인 기록으로 계산해요.
    1. 모비라이프 API 키 — 화면 위쪽 "API 키" 칸에 본인 키를 입력하세요. 없으면 발급처에서 먼저 받아야 해요.

    2. 아이템 감시하기 — 아이템 이름을 검색해 [조회]를 누르면 자동으로 감시 목록에 추가돼요. 목록에서 아이템을 클릭하면 그 아이템 차트로 바로 이동해요.

    3. 브라우저 알림 — "🔔 알림 방식"에서 "알림 켜기"를 누르면 조건 도달 시 윈도우/맥 알림이 떠요. 카카오톡 설정 없이도 이것만으로 충분히 쓸 수 있어요.

    4. 카카오톡 알림(선택) — 폰으로도 받고 싶으면 Kakao Developers(developers.kakao.com)에서 앱을 만들고 JavaScript 키·REST API 키를 위 칸에 입력하세요. 이때 플랫폼 도메인과 Redirect URI를 지금 이 페이지 주소로 정확히 등록해야 하고, 동의항목에서 "카카오톡 메시지 전송"을 켜둬야 해요. 이 단계가 좀 까다로우니, 안 되면 편하게 다시 물어보세요.

    5. 가격 알림 설정 — 감시 목록에서 "상세"를 누르면 목표가/퍼센트/트레일링(고점 대비 하락) 중 원하는 방식으로 조건을 걸 수 있어요.

    6. 탭을 열어두세요 — 이 앱은 브라우저 탭이 열려 있어야 감시가 돌아가요. 탭을 닫거나 컴퓨터가 잠자기 모드로 들어가면 그 순간부터 멈춰요.
